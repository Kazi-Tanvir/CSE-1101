# 📁 Assignment 10 Data Files

This directory contains the input course marks files and output result marksheets for **Assignment 10** (Self-Referential Struct / Linked List Student Grading System):

| File | Course Code / Type | Content Description |
|---|---|---|
| `name_cg.txt` | Input | Student Roll numbers and full names |
| `1101_CSE.txt` | CSE 1101 | Quiz, Assignment, Midterm, Attendance, Final marks |
| `1101L_CSE.txt` | CSE 1101L | Lab marks |
| `1102_CSE.txt` | CSE 1102 | Course marks |
| `1103_STAT.txt` | STAT 1103 | Statistics course marks |
| `1105_GE.txt` | GE 1105 | General Education marks |
| `1106_SE.txt` | SE 1106 | Software Engineering marks |
| `1107_MATH.txt` | MATH 1107 | Mathematics course marks |
| `result.txt` | Output | Full student result marksheet generated via self-referential linked list |
