# 📁 Class Data Files

This directory contains input and output datasets used by the class programs for File I/O, encryption/decryption, sorting, and binary storage exercises.

| File | Purpose / Used By |
|---|---|
| `char_input.txt` / `char_output.txt` | Character-by-character file reading & writing (`21_file_basic.c`) |
| `line_input.txt` / `line_output.txt` | Line-by-line file I/O operations (`21_file_basic.c`) |
| `formatted_input.txt` / `formatted_output.txt` | Formatted file I/O (`21_file_basic.c`) |
| `name_cg_encrypted.txt` / `name_cg_decrypted.txt` | Binary & shift encryption/decryption files (`27_binary_encryption.c`, `28_shift_encryption.c`) |
| `sorted_cg.txt` | Output of sorted CGPA records (`25_file_sort_cg.c`) |
| `students.bin` | Binary struct file records (`26_struct_student_info.c`) |
